# Security Policy

## Supported Release Channels

- `dev` / `develop`: active development (pre-release quality)
- `main`: promoted/manual releases

## Reporting a Vulnerability

Please do not open public issues for security vulnerabilities.

Use GitHub private advisories:
- https://github.com/BUZASLAN128/cerberus-windows-agent/security/advisories/new

Include:
- affected version/tag
- impact summary
- reproducible steps or PoC
- suggested remediation (if available)

## Response Targets

- Initial triage: within 72 hours
- Risk classification: High / Medium / Low
- Fix plan and patch timing based on severity and exploitability
