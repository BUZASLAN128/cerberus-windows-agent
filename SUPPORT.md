# Support

## Before Opening an Issue

1. Check `README.md` troubleshooting section.
2. Run self-test:

```powershell
Cerberus.Agent.App.exe --self-test --self-test-json
```

3. Confirm you are testing the expected branch/release (`dev` prerelease vs `main` promoted release).

## Where to Ask

- Bug or feature: GitHub Issues with templates
- Security concern: private advisory only (`SECURITY.md`)

## Information to Include

- Agent version and release tag
- Branch/channel (`dev`, `develop`, or `main`)
- Environment (Windows version, service/tray mode)
- Sanitized logs and exact reproduction steps
