# Code of Conduct

This repository expects respectful, professional collaboration.

## Our Standards

- Be constructive and specific in feedback
- Focus on technical outcomes, not personal attacks
- Assume good intent and ask clarifying questions
- Keep discussions relevant to repository goals and security

## Unacceptable Behavior

- Harassment, hate speech, threats, or discrimination
- Repeated disruptive/off-topic behavior
- Sharing sensitive information without authorization

## Enforcement

Maintainers may edit/remove content, lock threads, or block users for violations.

For serious concerns, use private channels or security advisory flow.
